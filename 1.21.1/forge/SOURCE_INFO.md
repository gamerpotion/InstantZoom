# Instant Zoom — Minecraft 1.21.1 / Forge

Source snapshot corresponding to the shared **v1.1.1** build.

Original source archive: `instantzoom-forge-1.21.1-1.1.1-sources.zip`.

Files in `src/main/` are copied unchanged from the original archive.
The code was originally assembled in separate projects, so use the corresponding
Minecraft 1.21.1 Forge development environment when porting or rebuilding.
This snapshot does not include a self-contained Gradle project. Start with the official loader MDK/example project and place src/main/ into it.

The default key is **C**, zoom is held (4x) and non-cinematic.
Check the version-specific Minecraft and loader APIs when porting.
